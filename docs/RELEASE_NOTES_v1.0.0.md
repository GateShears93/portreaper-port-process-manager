## PortReaper v1.0.0

First public release of PortReaper: a free, portable Port and Process Manager for Windows. See what is using a port and kill it in one click.

### Features
- Live list of all listening TCP/UDP ports with PID, process name and path
- Instant search by port, process name or path
- One-click kill for a process or a whole process tree
- Quick-free buttons for ports 3000, 3001, 4200, 5000, 5173, 8000, 8080, 8888, 9000
- Open `localhost:PORT` in the browser
- Copy PID, port and path
- Auto-refresh
- Confirmation before killing and protection for system processes
- 100% offline, no telemetry, portable

### Installation
1. Download `PortReaper.zip` below
2. Extract the archive
3. Run `PortReaper.exe` (right-click -> Run as administrator for elevated processes)

### Notes
- Windows may show a SmartScreen warning because the app is not code-signed yet. Some antivirus tools can flag process-management utilities. The full source code is in this repository.
- Killing a process can cause unsaved data loss in that program.
