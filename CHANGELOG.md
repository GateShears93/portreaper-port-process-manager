## [1.0.0] - 2026-10-16

### Added
- Live list of listening TCP/UDP ports with PID, process name and path
- Search and filter by port, process name or path
- One-click kill for a process and for a process tree
- Quick-free buttons for popular development ports
- Open `localhost:PORT` in the browser
- Copy PID, port and path
- Auto-refresh
- Confirmation dialog and protection for system processes
