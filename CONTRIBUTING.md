# Contributing to PortReaper

Thanks for helping! Here is how to contribute.

## Reporting bugs
Open an issue using the **Bug report** template. Include your Windows version, PortReaper version, steps to reproduce and what you expected to happen.

## Suggesting features
Open an issue using the **Feature request** template and describe the problem you want to solve.

## Pull requests
1. Fork the repository and create a branch: `git checkout -b feature/my-change`
2. Make your change and keep it focused on one thing.
3. Test it locally.
4. Update `CHANGELOG.md` under `[Unreleased]`.
5. Open a pull request and fill in the template.

## Commit messages
Use short, clear messages in the imperative mood, for example: `Add process tree kill`.

## Code of conduct
By participating you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
